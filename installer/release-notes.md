[Compositor](https://github.com/robbietilton/Compositor)(macOS, MIT)를 윈도우에서 쓸 수 있게 다시 만든 한국어 이미지 편집기입니다. 편집 › 환경 설정 › 언어에서 영어와 한국어를 바꿀 수 있습니다.

## 1.0.8에서 바뀐 것

- **정확한 픽셀 옮기기(`put_pixels`)**: 그림 파일의 픽셀을 색 손실 없이 그대로 레이어에 옮깁니다. 영역을 골라 원하는 위치에, 새 레이어나 기존 레이어에, 선택 영역 안에만 넣을 수 있습니다. 붓질을 수십만 번 하거나 색 수를 줄일 필요가 없습니다.
- **펜 도구(`add_path`)**: SVG 패스(직선·곡선·호)로 자유 도형을 그려 레이어, 마스크, 선택 영역으로 만듭니다. 실루엣과 잘라낸 틈을 마스크로 만들 수 있습니다.
- **비교(`compare_image`)**: 레퍼런스와 비교해 유사도, 가장 다른 영역, 차이를 빨갛게 표시한 이미지를 줍니다.
- **작업 방법 가이드**: AI 안내에 일하는 방법과 작업 유형별 순서(레퍼런스 재현·새로 디자인·사진 보정)가 들어갔습니다. `compositor guide topic=reproduce`로 봅니다.
- **작업 규칙 기본값**에 레퍼런스 재현 규칙이 추가됐습니다. 이미 만들어진 `ai-rules.md`는 그대로 두므로, 새 기본값을 쓰려면 `%APPDATA%\Compositor_korean_win\ai-rules.md`를 지우세요. 다음 실행 때 새 기본값으로 다시 만들어집니다.

## 1.0.7에서 바뀐 것

- `close_document`로 닫은 문서가 다음 AI 명령에서 새 `docN` ID로 다시 등록되던 문제를 고쳤습니다. 자동화 세션과 실제 편집기 탭이 함께 닫힙니다.

## 1.0.6에서 바뀐 것

- `compositor` 명령이 응답을 30초가 아니라 **최대 5분** 기다립니다. 사용자가 편집 중이라 요청이 대기하면 그 사실을 알려 주고, `COMPOSITOR_TIMEOUT` 환경변수(초, 0은 무제한)로 바꿀 수 있습니다.
- 명령이 시간 초과로 끝나면 아직 시작되지 않은 요청은 창에서 철회됩니다. 나중에 몰래 적용되어 다시 보낸 요청과 중복되지 않습니다.
- `layer=007`처럼 0으로 시작하는 값이 숫자 7로 바뀌지 않고 글자 그대로 전달됩니다.
- `text`·`prompt`에서 `\\n`으로 역슬래시와 n을 글자 그대로 쓸 수 있고, 다른 인수의 윈도우 경로(`C:\new\...`)에 든 `\n`이 더 이상 줄바꿈으로 바뀌지 않습니다.
- **AI 손 도구**: AI가 좌표로 브러시·지우개·복제 도장·스팟 힐링·흐림(마스크에도), 유동화, 뒤틀기, 네 모서리 왜곡·원근을 씁니다.
- **AI 선택 영역**: 사각형·타원·올가미·마술봉·레이어 픽셀로 선택하고 더하기·빼기·교차, 반전·확장·축소·이동·회전, 페더를 줄 수 있습니다. 칠하기·필터·마스크가 선택 영역을 따르고, 열린 창에서는 사람과 AI가 선택 영역을 함께 씁니다. 선택 영역 채우기·지우기·내용 인식 채우기와 선택 영역을 새 레이어로 복사·잘라내기도 됩니다.
- **AI 마스크·조정**: 선택 영역·이미지로 마스크를 만들고 페더·반전을 줄 수 있습니다. 레벨·곡선은 채널별로, 색조/채도는 색 범위별로 조정하고, 만든 조정 레이어의 값을 나중에 일부만 바꿀 수 있습니다. 필터에 렌즈 보정·핀치·구형화·돌리기·물결·극좌표·반전과 조정 굽기가 추가됐습니다.
- **AI 확인·묶음**: 렌더에서 영역을 픽셀 그대로 확대하고 몇 레이어만 보거나 숨길 수 있습니다. 여러 명령을 `batch`로 묶으면 실행 취소 한 단계가 되고, 하나라도 실패하면 전부 되돌아갑니다.
- 그룹 안이나 클리핑 그룹 사이에 AI가 레이어를 넣을 때 그룹 맨 위에 정확히 들어가고, 클리핑된 레이어가 풀려 일부만 보이던 문제를 고쳤습니다.

## 1.0.5에서 바뀐 것

- `compositor --version` 또는 `compositor version`으로 앱을 열지 않고 설치 버전을 확인할 수 있습니다.
- 실행 중인 앱의 로컬 통로에 접근할 수 없을 때 새 창을 반복해서 열지 않고, 권한 거부·연결 실패·응답 시간 초과를 구분해 안내합니다.
- 앱 시작 중 프로세스가 종료되면 즉시 알려 주며, 시작 및 도구 응답에 명확한 제한 시간을 적용했습니다.
- Compositor 창은 한 번만 실행됩니다. 다시 실행하면 기존 창을 앞으로 가져옵니다.
- 한국어 인터페이스에서는 AI 작업 안내의 사용법, 종료 코드와 연결 문제 해결 안내도 한국어로 표시됩니다.

## 1.0.4에서 바뀐 것

- 설치 화면의 "추가 작업"에 **AI가 쓰는 compositor 명령어 등록** 체크박스가 생겼습니다. 기본으로 켜져 있고, 끄면 PATH를 건드리지 않습니다.

## 1.0.3에서 바뀐 것

- **`compositor` 명령어**: 설치하면 명령어가 PATH에 등록됩니다. AI에게 "컴포지터 켜 놨어. `compositor` 명령어로 연결해서 작업해 줘"라고만 하면, AI가 가이드(작업 규칙과 도구 목록)를 읽고 켜 둔 창에서 작업합니다. Compositor가 꺼져 있으면 명령이 알아서 켭니다. 제거하면 PATH에서도 빠집니다.
- AI가 결과 확인용으로 만드는 이미지는 최근 20장만 남기고 자동으로 지웁니다.

## 1.0.2에서 바뀐 것

- **AI 작업 연결(등록 불필요)**: 도움말 › AI 작업 안내 복사로 받은 안내문을 AI(Claude, Codex 등)에게 붙여넣으면, 켜 둔 창에서 바로 작업합니다. 마우스·키보드를 쓰지 않고 로컬 통로로 연결되며, 도구 호출마다 실행 취소 한 단계가 됩니다.
- **AI 작업 규칙**: 도움말 › AI 작업 규칙 편집에서 AI가 따를 규칙(레이어 그룹 구조, 이름 짓기 등)을 고칠 수 있습니다.
- **글자 범위별 스타일**: 텍스트 일부만 크기·색·글꼴·굵게·기울임을 바꿀 수 있고, 포토샵 PSD와 서로 주고받습니다.
- **포토샵 문자 레이어 호환**: Compositor에서 저장한 PSD의 텍스트가 포토샵에서 편집 가능한 문자 레이어로 열립니다.
- **왜곡·뒤틀기 멈춤 수정**: 기울이기·원근·왜곡에서 점을 끌 때 프로그램이 멈추던 문제를 고쳤습니다.
- 이동 도구에서 텍스트를 더블클릭하면 문자 도구로 바뀝니다.

## 어떤 파일을 받나요

| 파일 | 내용 |
|---|---|
| `Compositor_korean_win-ai-…-setup.exe` | **AI 포함판 설치 파일.** 필터 › 배경 제거(BiRefNet-lite)가 됩니다. 약 150 MB |
| `Compositor_korean_win-…-setup.exe` | **미포함판 설치 파일.** 배경 제거만 빠지고 나머지는 같습니다 |
| `….zip` | 설치 없이 쓰는 휴대용. 압축을 풀고 `Compositor_korean_win.exe`를 실행합니다 |
| `SHA256SUMS.txt` | 파일 무결성 확인용 해시 |

- **설치 위치**: `%LOCALAPPDATA%\Programs\Compositor_korean_win` (사용자별 설치, 관리자 권한 불필요)
- **제거**: 설정 › 앱 › 설치된 앱(또는 제어판 › 프로그램 추가/제거)에서 제거하면 프로그램 폴더와
  설정(`%APPDATA%\Compositor_korean_win`)까지 모두 지워집니다.
- 두 판은 같은 프로그램으로 취급됩니다. 한쪽 위에 다른 쪽을 설치하면 교체됩니다.

## 처음 실행할 때

코드 서명이 없어서 Windows SmartScreen이 "Windows의 PC 보호" 창을 띄울 수 있습니다.
**추가 정보 › 실행**을 누르면 설치됩니다. 파일이 이 저장소에서 받은 것인지는 `SHA256SUMS.txt`로 확인할 수 있습니다.
