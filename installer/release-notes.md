[Compositor](https://github.com/robbietilton/Compositor)(macOS, MIT)를 윈도우에서 쓸 수 있게 다시 만든 한국어 이미지 편집기입니다. 편집 › 환경 설정 › 언어에서 영어와 한국어를 바꿀 수 있습니다.

## 1.0.4에서 바뀐 것

- 설치 화면의 "추가 작업"에 **AI가 쓰는 compositor 명령어 등록** 체크박스가 생겼습니다. 기본으로 켜져 있고, 끄면 PATH를 건드리지 않습니다.

## 1.0.3에서 바뀐 것

- **`compositor` 명령어**: 설치하면 명령어가 PATH에 등록됩니다. AI에게 "컴포지터 켜 놨어. `compositor` 명령어로 연결해서 작업해 줘"라고만 하면, AI가 가이드(작업 규칙과 도구 목록)를 읽고 켜 둔 창에서 작업합니다. Compositor가 꺼져 있으면 명령이 알아서 켭니다. 제거하면 PATH에서도 빠집니다.
- AI가 결과 확인용으로 만드는 이미지는 최근 20장만 남기고 자동으로 지웁니다.

## 1.0.2에서 바뀐 것

- **AI 작업 연결(등록 불필요)**: 도움말 › AI 작업 안내 복사로 받은 안내문을 AI(Claude, Codex 등)에게 붙여넣으면, 켜 둔 창에서 바로 작업합니다. 마우스·키보드를 쓰지 않고 로컬 통로로 연결되며, 도구 호출마다 실행 취소 한 단계가 됩니다.
- **AI 작업 규칙**: 도움말 › AI 작업 규칙 편집에서 AI가 따를 규칙(레이어 그룹 구조, 이름 짓기 등)을 고칠 수 있습니다.
- **글자 범위별 스타일**: 텍스트 일부만 크기·색·글꼴·굵게·기울임을 바꿀 수 있고, 포토샵 PSD와 서로 주고받습니다.
- **포토샵 문자 레이어 호환**: Compositor에서 저장한 PSD의 텍스트가 포토샵에서 편집 가능한 문자 레이어로 열립니다.
- **왜곡·뒤틀기 멈춤 수정**: 기울이기·원근·왜곡에서 점을 끌 때 프로그램이 멈추던 문제를 고쳤습니다.
- 이동 도구에서 텍스트를 더블클릭하면 문자 도구로 바뀝니다.

## 어떤 파일을 받나요

| 파일 | 내용 |
|---|---|
| `Compositor_korean_win-ai-…-setup.exe` | **AI 포함판 설치 파일.** 필터 › 배경 제거(BiRefNet-lite)가 됩니다. 약 150 MB |
| `Compositor_korean_win-…-setup.exe` | **미포함판 설치 파일.** 배경 제거만 빠지고 나머지는 같습니다 |
| `….zip` | 설치 없이 쓰는 휴대용. 압축을 풀고 `Compositor_korean_win.exe`를 실행합니다 |
| `SHA256SUMS.txt` | 파일 무결성 확인용 해시 |

- **설치 위치**: `%LOCALAPPDATA%\Programs\Compositor_korean_win` (사용자별 설치, 관리자 권한 불필요)
- **제거**: 설정 › 앱 › 설치된 앱(또는 제어판 › 프로그램 추가/제거)에서 제거하면 프로그램 폴더와
  설정(`%APPDATA%\Compositor_korean_win`)까지 모두 지워집니다.
- 두 판은 같은 프로그램으로 취급됩니다. 한쪽 위에 다른 쪽을 설치하면 교체됩니다.

## 처음 실행할 때

코드 서명이 없어서 Windows SmartScreen이 "Windows의 PC 보호" 창을 띄울 수 있습니다.
**추가 정보 › 실행**을 누르면 설치됩니다. 파일이 이 저장소에서 받은 것인지는 `SHA256SUMS.txt`로 확인할 수 있습니다.
